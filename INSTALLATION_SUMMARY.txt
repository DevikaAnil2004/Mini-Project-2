================================================================================
                         QUICK START (5 MINUTES)
================================================================================

STEP 1: Install Dependencies
  $ pip install -r requirements.txt

STEP 2: Create MySQL Database
  $ mysql -u root -p
  > CREATE DATABASE cricketiq;
  > EXIT;

STEP 3: Configure .env
  Edit .env and update:
  MYSQL_USER=root
  MYSQL_PASSWORD=your_password
  MYSQL_DATABASE=cricketiq

STEP 4: Initialize Database
  $ python init_db.py

STEP 5: Run Application
  $ python app.py

STEP 6: Open Browser
  http://localhost:5000

                       SETUP SCRIPT OPTIONS
================================================================================

Automated Setup (Recommended):

Linux/Mac:
  $ chmod +x setup.sh
  $ ./setup.sh
  
  Creates venv, installs dependencies, configures .env,
  creates database, initializes with sample data

Windows:
  > setup.bat
  
  Creates venv, installs dependencies, creates .env file
  (MySQL database needs manual creation)

Manual Setup:
  1. Create virtual environment
  2. Install requirements.txt
  3. Edit .env with credentials
  4. Run init_db.py
  5. Start Flask app

================================================================================
                      TROUBLESHOOTING QUICK LINKS
================================================================================

MySQL Connection Error:
  → Check .env file for correct credentials
  → Ensure MySQL is running
  → Verify database exists

Port 5000 In Use:
  → Change port in app.py line 213
  → Or kill process: lsof -ti:5000 | xargs kill -9

Module Not Found:
  → Run: pip install -r requirements.txt
  → Ensure virtual environment is activated

Database Issues:
  → Run: python init_db.py to reset
  → Check MySQL for existing database

For more help, see README.md section "Troubleshooting"
